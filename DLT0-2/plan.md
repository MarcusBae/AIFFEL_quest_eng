# 과제 계획서: Local LLM 기반 C++ 코딩 에이전트 구축

## 1. 배경 및 목적

개발 환경에서 생성형 AI(LLM)의 활용은 필수적이나, 기업의 핵심 자산인 소스 코드의 외부 유출 우려로 인해 클라우드 기반 AI 서비스(ChatGPT, Claude 등) 사용에 제약이 있다.

본 과제는 인터넷 연결이 차단된 완전한 **오프라인(Air-gapped) 환경**의 로컬 머신(Windows)에서 동작하는 **C++ 특화 코딩 에이전트 시스템**을 구축하는 것을 목적으로 한다. 

이를 통해 코드 보안을 완벽히 유지하면서 AI를 활용한 코드 리뷰, 분석, 자동화 작성을 수행할 수 있다.

## 2. 시스템 아키텍처 및 구성 요소

전체 시스템은 로컬 추론 엔진인 **Ollama**를 중심으로, 사용 목적과 자율성 단계에 따라 3가지 인터페이스(Continue, Cody, OpenHands)를 계층적으로 구성한다. 

모든 데이터는 `localhost` 내부에서만 처리된다.

## 3. 구축 단계별 계획

난이도와 자율성이 낮은 순서부터 단계별로 구축 및 검증을 진행한다.

### Step 1. 대화용 및 즉각적인 코드 리뷰 환경 구축
* **목표:** IDE(VS Code) 내에서 특정 코드 블록에 대한 즉각적인 질문 답변 및 리뷰 환경 구동.
* **조합:** **Ollama + Qwen2.5-Coder + Continue**
* **주요 활동:**
    * Windows용 Ollama 설치 및 실행.
    * `ollama pull qwen2.5-coder:7b` (또는 32b) 모델 다운로드.
    * VS Code에 `Continue` 확장 설치 및 로컬 Ollama API(`localhost:11434`) 연결 설정.
    * C++ 코드 선택 후 "메모리 누수 분석", "리팩토링 제안" 등의 질의 테스트.

### Step 2. 프로젝트 단위 정밀 분석 환경 구축
* **목표:** 단일 파일이 아닌 프로젝트 전체의 함수 호출 관계, 의존성, 심볼을 파악한 컨텍스트 인식 답변 환경 구동.
* **조합:** **Sourcegraph Cody (Local Mode)** (+ Ollama)
* **주요 활동:**
    * VS Code에 `Cody AI` 확장 설치.
    * 설정에서 'Local context (RAG)' 활성화 및 Ollama 백엔드 지정.
    * C++ 프로젝트 폴더 인덱싱 수행.
    * `@codebase` 명령어를 활용하여 "이 프로젝트의 클래스 아키텍처를 설명해줘"와 같은 프로젝트 전반의 질문 테스트.

### Step 3. 자율형 자동화 에이전트 환경 구축
* **목표:** 고수준의 자연어 명령(예: "분석 보고서 작성 및 파일 생성")을 받아 스스로 계획을 수립하고 터미널 명령과 파일 시스템을 제어하여 과업을 완수하는 에이전트 구동.
* **조합:** **OpenDevin / OpenHands (Local Docker)** (+ Ollama)
* **주요 활동:**
    * Windows용 Docker Desktop 설치 및 WSL2 환경 설정.
    * OpenHands Docker 컨테이너 실행 및 Ollama 백엔드 연결.
    * "내 C++ 소스 폴더를 읽고, `analysis_report.md` 파일에 보안 취약점 분석 결과를 작성해줘"와 같은 자율 과업 수행 테스트.

## 4. 검증 및 활용 계획
